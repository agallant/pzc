# Phone Zombies Commute

A comic arcade game for phones and tablets. Cross a busy, high-functioning city to catch your train
while everyone around you walks head-down, poking at a phone. Bump into a phone zombie and you lose
a heart. Lose them all and the only way to continue is to take a real walk, phone in your pocket.

**Play it:** https://agallant.github.io/pzc/

Plans and design notes are in [ROADMAP.md](ROADMAP.md).

## Install to the home screen

- **iPhone / iPad (Safari):** Share, then **Add to Home Screen**.
- **Android (Chrome):** menu, then **Install app** (or **Add to Home screen**).

After the first visit the game works offline.

## Run it locally

```sh
npm ci
npm run dev        # dev server with hot reload
npm test           # unit tests (simulation and level generator)
npm run typecheck  # tsc --noEmit
npm run build      # static site in dist/
npm run preview    # serve the production build
```

Node 24 (see `.nvmrc`). Set `BASE_PATH=/pzc/` when building to mimic the GitHub Pages path.

Controls: drag anywhere to walk, hold **RUN** to hurry (it tires you out). On a keyboard, use
WASD or the arrow keys, and Shift or Space to run.

## Stack

TypeScript, Vite, Canvas 2D, Vitest. No runtime dependencies. The service worker and web app manifest
are generated by `vite.config.ts` at build time. Progress is stored in `localStorage` on the device.

```
src/game/      pure game logic: level generator, simulation, renderer
src/platform/  input, audio, storage
src/ui/        menus and HUD (DOM)
sw/            service worker template
tests/         unit tests
scripts/       icon generator (node scripts/make-icons.mjs)
```
